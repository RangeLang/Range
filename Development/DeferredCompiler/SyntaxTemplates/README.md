# Deferred syntax templates

These are the Range syntax declarations from commit `e5a35081a`, preserved when
structural parsing was assigned directly to C. They are reference material,
not active compiler inputs. The old template validator and capture bindings
were removed rather than made into a general parser.

Active grammar identities remain in `Language/Grammar`. Literal patterns and
default type relationships remain in `Language/Macros` and `Language/Types`.
