# Range documentation

This folder contains architecture records and working handoffs. Executable
projects, benchmarks, examples, and generated build output do not belong here.

## Current

- `RangeCompilerDesignDirection.md` is the cumulative compiler architecture and
  accepted-checkpoint record.
- `CodexHandoff.md` is the current operational handoff.
- `RangeMemoryGraphSelfHostingPlan.md` describes the MemoryGraph direction.
- `RangeGraphDerivedConcurrencyPlan.md` and
  `GraphDerivedConcurrencyPost.md` describe graph-derived concurrency.
- `Diagrams` contains supporting architecture visuals.

## Archive

`Archive` preserves superseded compiler plans, handoffs, and reports for
historical reference. Archived documents are not statements of current
compiler behavior; current behavior must be verified against the Range-authored
compiler and its accepted proof gates.
